# 📝 Changelog - Yandex Feed Generator Pro

## Версия 5.0.0 - Major Refactoring (04.12.2025)

### 🔧 Рефакторинг:

1. **Удалены deprecated методы из `class-feed-generator-v2.php`**
   - `collect_entities()` - заменён на YFGP_Entity_Collector
   - `build_offers_v2()` - заменён на YFGP_Offer_Builder
   - `find_base_service()`, `handle_no_services()`, `find_any_service_with_price()`
   - `is_service_suitable_for_primary_removed()`

2. **Консолидация Field Mappers**
   - Удалён `class-field-mapper.php` (базовый класс)
   - Удалён `class-field-mapper-v3.php` (прокси)
   - `YFGP_Field_Mapper_V2` теперь standalone класс с собственными helper методами
   - Все вызовы V3 заменены на прямое использование `YFGP_Field_Mapper_Unified`

3. **Исправлены кракозябры в комментариях**
   - Главные комментарии переведены на английский
   - Улучшена читаемость кода

4. **Очистка мёртвого кода**
   - Удалён `class-universal-field-loader.php` (не использовался)
   - Реализован `YFGP_Cron_Manager` (вместо заглушек v2.4.0)

## Версия 1.2.1 - Исправление ошибок (14.10.2025)

### 🐛 Исправлено:

1. **Критическая ошибка с разбором ФИО**

   - Исправлена проблема, когда в поле "Фамилия" попадало полное ФИО
   - Добавлена автоматическая проверка и исправление, если в фамилии обнаружены пробелы
   - Теперь плагин корректно разбивает "Сальный Дмитрий Валерьевич" на:
     - Фамилия: "Сальный"
     - Имя: "Дмитрий"
     - Отчество: "Валерьевич"

2. **Улучшен интерфейс маппинга полей**

   - Добавлена возможность указать отдельные поля для Фамилии, Имени и Отчества
   - Если указаны отдельные поля - они будут использоваться вместо автоматического разбора
   - Приоритет: отдельные поля > автоматический разбор из полного имени

3. **Добавлены новые возможности маппинга**
   - Поддержка отдельных полей: `surname`, `firstname`, `patronymic`
   - Улучшена обработка ошибок при маппинге
   - Добавлено подробное логирование для отладки

### 📋 Обновленная структура маппинга:

```php

// ИЛИ

'firstname' => 'custom_firstname', // Отдельное поле для имени
'patronymic' => 'custom_patronymic', // Отдельное поле для отчества
```

## 🚀 Установка обновления:

### Метод 1: Через WordPress Admin (рекомендуется)

1. Скачайте архив `yandex-feed-generator-pro-v1.2.1.zip`
2. Перейдите в WordPress: **Плагины → Добавить новый → Загрузить плагин**
3. Выберите архив и нажмите **Установить**
4. **Активируйте** плагин

### Метод 2: Через FTP/файловый менеджер

1. Удалите старую папку `wp-content/plugins/yandex-feed-generator-pro`
2. Загрузите новую папку плагина
3. Активируйте плагин в WordPress

### Метод 3: Копирование в Docker

```powershell
# Из директории D:\Сайты
robocopy "Плагины\yandex-feed-generator-pro" "new project\wordpress-docker\wp-content\plugins\yandex-feed-generator-pro" /E /PURGE
```

## 📝 После обновления:

1. Перейдите в **Yandex Feed → Маппинг полей**
2. Проверьте настройки маппинга ФИО
3. Если нужно - укажите отдельные поля для Фамилии, Имени, Отчества
4. Нажмите **Сохранить маппинг**
5. Перейдите в **Yandex Feed → Превью**
6. Нажмите **Сгенерировать фид**
7. Проверьте результат
