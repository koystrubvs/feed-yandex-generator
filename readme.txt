Универсальный генератор YML фидов для Яндекс.Вебмастера с поддержкой ACF и JetEngine

== Description ==

**Yandex Feed Generator Pro** - мощный плагин для автоматической генерации YML фидов для Яндекс.Вебмастера.

= Основные возможности =

* 🎯 Поддержка любых типов записей (CPT)
* 🔧 Работа с полями ACF и JetEngine
* 🗺️ Гибкий маппинг полей WordPress → YML элементы
* ⏰ Автоматическое обновление по расписанию
* 👁️ Превью фида перед публикацией
* 💾 История версий и бэкапы
* 🤖 Автоподбор услуг для записей без связей
* ✅ Валидация YML перед публикацией

= Поддерживаемые категории =

* Врачи (с поддержкой специальностей через `<sets>`)
* Товары (Яндекс.Маркет)
* Услуги

= Требования =

* WordPress 5.8+
* PHP 7.4+
* Опционально: ACF Pro или JetEngine

= Использование =

1. Установите и активируйте плагин
2. Перейдите в **Yandex Feeds → Настройки**
3. Заполните информацию о компании
4. Настройте маппинг полей в **Маппинг полей**
5. Сгенерируйте фид в **Генерация фида**
6. Скопируйте URL фида и добавьте в Яндекс.Вебмастер

== Installation ==

1. Загрузите папку плагина в `/wp-content/plugins/`
2. Активируйте плагин в разделе "Плагины" WordPress
3. Перейдите в **Yandex Feeds** для настройки

== Frequently Asked Questions ==

= Поддерживаются ли кастомные поля? =

Да! Плагин автоматически определяет все доступные поля ACF, JetEngine и стандартные мета-поля.

= Можно ли редактировать фид вручную? =

Да! В разделе "Генерация фида" вы можете просмотреть и отредактировать XML перед публикацией.

= Как работает автообновление? =

Плагин использует WordPress Cron для автоматического обновления фида по заданному расписанию (ежечасно, ежедневно, еженедельно).

= Где хранятся фиды? =

Фиды сохраняются в `/wp-content/uploads/feed/` и доступны по URL: `https://ваш-сайт.ru/wp-content/uploads/feed/doctors.yml`
